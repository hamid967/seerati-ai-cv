# Phase 15 Motion System

Motion tokens are Instant 100ms, Fast 160ms, Standard 240ms, Emphasis 360ms, and a 6–8 second intro sequence only when explicitly enabled. Normal product interactions should prefer transform and opacity and must not animate PDF, Print, long text, screen-reader content, or the critical first viewport.

Every motion feature requires a reduced-motion alternative, visible focus preservation, keyboard operation, and a measurement showing no long task over 50ms attributable to the feature. The intro, if implemented later, must be dynamically loaded and excluded from the initial critical bundle.
