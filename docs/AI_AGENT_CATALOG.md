# Saudi Career Intelligence Agent Catalog

The product should expose bounded specialist behaviors rather than autonomous claims. Required agents are Graduate, Experienced Professional, Executive, Technical and Engineering, Healthcare, Government Sector, Finance and Banking, Sales and Marketing, Operations and Logistics, Arabic Writing, English Writing, ATS, Translation, Achievement Coach, and Final CV Reviewer.

Every agent must ask for missing facts, never invent employers, dates, degrees, skills, or metrics, clearly mark suggestions, provide reversible diffs, and state when advice is advisory. Secrets remain server-side and requests require explicit user action.
