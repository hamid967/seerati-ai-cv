# Phase 17 User Test Plan

## Status

No user study has been run in this Phase 17 implementation. This document is a protocol, not a results claim.

## Proposed sample

Recruit 30 Saudi participants across graduates, employees, leaders, and recruiting specialists, including men and women, Arabic and English users, with a majority completing the journey on mobile. Recruitment and consent must be handled outside the repository and must not upload CV text, prompts, screenshots containing personal data, or direct identifiers to CI or telemetry.

## Measures

Measure whether participants find the main CTA within five seconds, understand free creation, understand optional registration, understand the memory-only privacy boundary, rate the professional impression, recognize the Saudi identity without government affiliation, use the city/template interactions, understand whether the intro helps or annoys them, reach the editor, export the first PDF, and prefer a template category.

## Targets

| Measure                             | Target |
| ----------------------------------- | -----: |
| CTA clarity                         |   ≥90% |
| Free creation comprehension         |   ≥90% |
| Optional registration comprehension |   ≥90% |
| Privacy comprehension               |   ≥90% |
| Professional design satisfaction    |   ≥4/5 |
| Intro not a barrier                 |   ≥90% |
| Mobile journey completion           |   ≥85% |

## Privacy-safe evidence

Store only aggregate counts, task completion, timings, ratings, and coded qualitative themes. Do not store CV content, prompts, model responses, account identifiers, raw recordings, or unredacted screenshots. Results remain pending until the study is actually conducted and reviewed.
