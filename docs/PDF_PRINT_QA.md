# PDF and Print QA

Required fixtures are Arabic-only, English-only, bilingual, long executive, short graduate, empty optional fields, long URLs and email addresses, and page-break edge cases. Acceptance requires selectable text, embedded/open Arabic fonts, A4 dimensions, deterministic page breaks, no clipped lines, no watermark, and a browser print fallback.

The current implementation should be validated in Chrome, Edge, Safari/WebKit, and responsive mobile print flows before release.
