# Originality and License Report

**Project:** Seerati AI CV — Phase 17  
**Direction:** Saudi Future Professional  
**Date:** 2026-08-13

## Decision

Phase 17 will be implemented as original product work inside the existing TanStack Start, React, TypeScript, and Tailwind codebase. The benchmark is for principles only. No paid Webflow template, cloneable community site, external HTML/CSS/JavaScript, recognizable layout, image, icon, font, animation, government logo, or marketing copy is being copied or redistributed.

## Asset policy

Every future font, icon, illustration, image, sound, animation package, and data visualization must be recorded before use with its source URL, license, version, local path, intended use, attribution requirement, and reviewer. Assets without a clear license are rejected. Generated assets must be labeled as generated and must not imitate a named brand, landmark, or copyrighted template.

## Code policy

Components will be authored in the repository and reviewed for semantic HTML, logical CSS properties, RTL/LTR behavior, reduced motion, print safety, and bundle impact. Any external dependency requires a package license review and a performance justification. Existing privacy, AI, ATS, Supabase, and admin logic cannot be altered for visual polish without a separate reviewed manifest.

## Saudi cultural safety

City names and patterns are directional design themes, not claims of government affiliation or official city branding. No Saudi authority logo, government mark, official seal, protected landmark representation, or unsupported sector statistic may be used. Arabic copy receives review for grammar, tone, cultural appropriateness, and non-discrimination before release.

## Release gate

A visual result cannot be marked complete merely because it resembles a premium reference. It must pass originality review, license review, human visual review, accessibility, performance, privacy, PDF/Print, and browser checks. A missing license entry is a blocking release finding.
