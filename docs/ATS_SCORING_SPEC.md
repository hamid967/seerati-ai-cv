# ATS Scoring Specification

ATS results are advisory and must never be presented as a guarantee. The rules engine should score contact completeness, section structure, chronology, job-title alignment, keyword coverage, measurable achievements, readability, formatting compatibility, language consistency, and missing or excessive content.

Each finding must include the observed evidence, category score, actionable fix, confidence level, and a plain-language disclaimer. No external ATS service may receive CV data without explicit consent.
