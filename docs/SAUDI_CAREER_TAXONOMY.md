# Seerati Career Taxonomy v0.1.0

هذه قاعدة مصطلحات عامة منسقة داخل Seerati لتسهيل البحث والمطابقة بالعربية والإنجليزية. **ليست تصنيفاً حكومياً أو تنظيمياً رسمياً، ولا تدعي تمثيل أي جهة توظيف أو جهة اعتماد.**

تحتوي النسخة الأولى على قطاعات عامة ومصطلحات مهنية شائعة بصيغ عربية وإنجليزية وبعض المرادفات. كل مصطلح يحمل version ووقت مراجعة ومصدر داخلي `seerati-curated-general`. لا يجوز استخدام هذه البيانات لإثبات أهلية نظامية أو ترخيص مهني.

## سياسة الاستخدام

يُستخدم التصنيف كإشارة مساعدة للبحث، taxonomy match، وتطبيع المصطلحات. لا يحول المصطلح إلى حقيقة في ملف المستخدم، ولا يضيف مهارة أو خبرة غير موجودة. عند وجود تطابق مصطلحي فقط، يعرض النظام ذلك كـ`taxonomy_match` ويطلب Evidence منفصلاً قبل اعتباره تطابقاً قوياً.

## الإصدار والتحميل

الإصدار الحالي هو `0.1.0`. يمكن تحميل القطاع عند الحاجة بدلاً من إدخال taxonomy كاملة في initial bundle. أي مصطلح جديد يحتاج مراجعة بشرية، source label، وتغيير version. المصطلحات التنظيمية أو المتغيرة لا تُضاف دون مصدر مؤرخ وقرار حوكمة.

## التغطية الأولية

تشمل النسخة قطاعات حكومية، تقنية، أمن سيبراني، هندسة، طاقة، صحة، مالية ومصرفية، محاسبة، موارد بشرية، مبيعات، تسويق، تشغيل، لوجستيات، سياحة، ضيافة، تعليم، قانون، عقارات، بناء، قطاع غير ربحي، إعلام، ثقافة، ورياضة.

## ما لا تفعله القاعدة

لا تصدر القاعدة توصية توظيف، ولا تصنف المرشح حكومياً، ولا تمنح اعتماداً، ولا تضمن اجتياز ATS، ولا تستنتج مستوى خبرة المستخدم من تشابه الكلمات. هذه وظائف advisory فقط، وتبقى قرارات المستخدم أو الجهة المختصة خارج النظام.
