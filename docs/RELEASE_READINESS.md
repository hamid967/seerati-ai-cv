# Release Readiness

The privacy-first anonymous foundation is implemented on branch `feat/privacy-first-free-cv`. Release remains blocked until lint, build, QA scripts, browser network inspection, import deletion checks, PDF fixtures, RTL/LTR checks, mobile checks, and a draft pull request review are complete.

Do not merge to `main` without owner approval. Known limitations include incomplete browser-level evidence and the need to review all import, telemetry, and server error paths for sensitive-value redaction.
